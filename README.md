# Superstore Sales Performance Dashboard

**Interactive Power BI Dashboard** | Excel + Power BI

## Project Overview
Full 3-page interactive sales performance dashboard analyzing **$2.30 million** in sales across **5,009 orders** from 2011–2014.

## Key Results
- **Total Sales**: $2.30M  
- **Total Net Profit**: $286.4K  
- **Profit Margin**: 12.47%  
- **Total Orders**: 5,009  
- **Average Order Value**: $458.61  

## Key Insights
- **Technology** is the strongest category (highest sales + 17.40% margin)
- **Furniture** has the lowest profitability (only 2.49% margin)
- West and East regions drive the majority of sales
- Top 3 states by net profit: **California ($76K)**, **New York ($74K)**, **Washington ($33K)**
- High discounts significantly hurt Furniture margins

## Dashboard Pages
- **Executive Overview** – High-level KPIs and trends
- **Profitability Deep Dive** – Detailed matrix, top states, discount impact, YoY growth
- **Key Insights & Actionable Recommendations** – Business insights and recommendations

## Tools Used
- Excel (data cleaning & pre-calculations)
- Power BI Desktop (data modeling, DAX measures, visualizations)
